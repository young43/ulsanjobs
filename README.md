# 울산 공공기관 채용공고 모아보기

울산 지역의 공공기관·지자체·교육청·대학 채용공고를 13개 사이트에서 자동으로 모아
검색·필터 가능한 사이트로 만들어 줍니다. 무기계약직, 공무직, 기간제 근로자 공고가 핵심 대상입니다.

## 자동 갱신 (등록 완료)

윈도우 작업 스케줄러에 **`UlsanJobs Daily Refresh`** 작업이 등록되어 있습니다.

- **매일 아침 8시**에 자동으로 수집 + 사이트 생성 (약 3~4분, 창 안 뜸)
- 그 시각에 PC가 꺼져 있었으면 **켠 뒤 자동으로 한 번 실행**합니다
- 실행 기록은 `logs\refresh.log` 에 쌓입니다

즉 아침에 `site\index.html` 만 열면 최신 공고가 보입니다. 즐겨찾기 해두세요.

상태를 확인하거나 끄고 싶을 때:

```powershell
Get-ScheduledTaskInfo -TaskName "UlsanJobs Daily Refresh"   # 마지막 실행 결과(0이면 정상)
Start-ScheduledTask   -TaskName "UlsanJobs Daily Refresh"   # 지금 즉시 한 번 실행
Disable-ScheduledTask -TaskName "UlsanJobs Daily Refresh"   # 잠시 중지
Unregister-ScheduledTask -TaskName "UlsanJobs Daily Refresh"  # 완전 삭제
```

**아티팩트(공유 링크)는 자동 갱신되지 않습니다.** 발행된 페이지는 보안 정책상 외부
사이트에 접속할 수 없어서, 링크를 최신으로 만들려면 Claude 에게 재발행을 요청해야 합니다.

## 직접 실행할 때

```bat
cd C:\workspace\NaverBlog\ulsanjobs
refresh.bat
```

수집과 사이트 생성을 한 번에 하고, 끝나면 `site\index.html` 을 브라우저로 엽니다.
소스가 17곳이라 3~4분 걸립니다. 브라우저를 안 열려면 `refresh.bat 60 noopen`.

따로 실행하려면:

```bat
python collect.py --days 60     :: 최근 60일 수집 -> data\jobs.json
python build_site.py            :: 사이트 생성   -> site\index.html
```

기간을 바꾸려면 `--days 30` 처럼 지정하면 됩니다.

## 결과물

| 파일 | 설명 |
|---|---|
| `data\jobs.json` | 수집 원본 데이터 |
| `site\index.html` | 더블클릭해서 바로 보는 사이트 |
| `site\artifact.html` | 온라인 발행(아티팩트)용 본문 |
| `logs\refresh.log` | 자동 실행 기록 |

## 배치 파일 주의

`refresh.bat` 과 `refresh_scheduled.bat` 은 **반드시 ASCII 로만** 작성해야 합니다.
cmd.exe 는 배치 파일을 OEM 코드페이지(한국어 윈도우는 949)로 읽어서, 파일 안에 한글이
있으면 줄 파싱이 깨지고 한글이 명령어로 해석됩니다. 한글 메시지는 파이썬 쪽에서 출력합니다.

## 수집 대상

| 사이트 | 담당 범위 | 울산 필터 방식 |

| 나라일터 | 국가기관·지자체·교육청·공공기관 | 키워드 `울산`/`울주` |
| 클린아이 잡플러스 | 지방공기업·출자출연기관 | `sidoCd=007007` |
| 하이브레인넷 | 대학·연구기관 | 근무지 코드 `A16` |
| 울산광역시 | 시 고시공고 중 채용글 | 사이트 자체가 울산 |
| 울산 중구 | 구 채용공고 게시판 | 〃 |
| 울산 남구·동구·북구 | 새올(eminwon) 채용공고 | 〃 |
| 울주군 | 군 채용공고 | 〃 |
| 울산교육청 (3개 게시판) | 교육공무직, 일반채용, 온라인채용 | 〃 |
| 춘해보건대학교 | 공지사항 중 채용글 | 〃 |
| 울산과학대학교 | 채용공고 게시판 | 〃 |

교육청 일반채용·온라인채용에는 사립학교(학교법인) 교직원 공고도 함께 들어옵니다.

**대학은 자체 홈페이지를 따로 봐야 합니다.** 하이브레인넷은 교수·연구원 공고 위주라
대학 행정직원·조교 공고가 빠집니다. 예를 들어 춘해보건대 "직원(간호학부) 채용 공고"는
하이브레인넷에 없고 대학 공지사항에만 올라옵니다.

## 알아둘 점

- **고용형태는 자동 분류입니다.** 공고 제목과 기관이 준 채용구분을 키워드로 나눈 것이라
  실제 계약 조건과 다를 수 있습니다. 지원 전 원문 공고를 꼭 확인하세요.
- **합격자 발표·심사 결과 안내글은 제외합니다**(`RESULT_NOTICE` 정규식). 다만
  "임용시험 시행계획 공고"는 실제 채용공고라서 남깁니다.
- **`게시판` 표시가 붙은 공고**(남구·동구·북구, 클린아이)는 해당 기관이 공고별 고유 주소를
  제공하지 않아 목록 페이지로 연결됩니다. 새올 시스템은 POST 폼 전송으로만 상세가 열리고,
  클린아이는 공고별 주소 자체가 없습니다.
- **잡알리오의 근무지가 "서울 외 14"** 처럼 나오는 공고는 여러 지역을 함께 뽑는 전국 단위
  채용이고, 그 안에 울산이 포함되어 있어 걸러지지 않고 남습니다.
- 지자체 게시판 대부분은 목록에 마감일이 없어 `마감일 미상`으로 표시됩니다.

## 사이트가 안 만들어질 때

`collect.py` 는 소스별로 실패를 격리해서, 한 곳이 죽어도 나머지는 계속 모읍니다.
실행 결과에 `ERR` 로 찍힌 소스가 있으면 그 사이트 구조가 바뀐 것입니다.
자세한 오류를 보려면:

```bat
set ULSANJOBS_DEBUG=1
python collect.py --days 60
```
